LLD Basics

I started learning LLD because I wanted to understand what actually happens before we start writing the code.

At first, I thought design basically meant making some diagrams and then coding. But LLD is more about deciding how the code itself should be structured so that the system doesn't become a mess when it grows.

What is LLD?

LLD = Low-Level Design

In simple words:

LLD is the detailed design of a system at the code and object level.

Here we think about things like:

What classes do we need?
What objects will exist?
What responsibility should each class have?
Which class should talk to which class?
What methods should they have?
Should we use an interface?
Where should inheritance or composition be used?
How can we make the design easy to change later?

So basically, we're going from:

"what should the system do?"
            ↓
"how should I structure the code to make it happen?"
