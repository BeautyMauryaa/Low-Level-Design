

# Why do we even need OOP?

Imagine a large application where everything is just random functions:

```text
createOrder()
calculatePrice()
makePayment()
sendEmail()
updateUser()
cancelOrder()
...
```

As the application grows, it becomes harder to understand:

* Which data belongs where?
* Which function should handle which responsibility?
* Which part is allowed to modify certain data?
* What happens when requirements change?

OOP gives us a way to organize this.



For example:

```text
User
 ├── user data
 └── user-related behavior

Order
 ├── order data
 └── order-related behavior

Payment
 ├── payment data
 └── payment-related behavior
```

Now the system has some structure.
