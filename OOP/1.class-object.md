

# Class vs Object

This is one of the first things to understand.

### Class

A class is basically a **blueprint**.

```text
Car
----------------
number
color
brand

start()
stop()
```

### Object

An object is an actual instance created from that class.

```text
Car 1
number = PB10AB1234
color = Black

Car 2
number = DL05XY9876
color = White
```

Both are `Car` objects, but their data is different.

In code:

```text
Car car1 = new Car("PB10AB1234", "Black");
Car car2 = new Car("DL05XY9876", "White");
```

So:

> **Class = blueprint**
> **Object = actual instance**
