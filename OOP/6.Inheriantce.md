
# 3. Inheritance
- ***A child class can reuse/extend the properties and behavior of a parent class.***


Example:

```text
              Vehicle
                 |
        ┌────────┼────────┐
        ↓        ↓        ↓
       Car      Bike     Truck
```

Common things can stay in `Vehicle`:

```text
Vehicle
----------------
speed
start()
stop()
```
Car and Bike can inherit those.
Then:

```text
Car
----------------
openTrunk()

Bike
----------------
kickStart()
```

In code:

```text
class Vehicle {
    start();
    stop();
}

class Car extends Vehicle {
    openTrunk();
}
```

The important relationship here is:

```text
Car IS-A Vehicle
Bike IS-A Vehicle
Truck IS-A Vehicle
```

That **IS-A** relationship is the key thing I look for before using inheritance.

- Notes: But don't use inheritance always just because two classes have some common fields
---
```text

#include <iostream>
#include <string>

// Parent Class (Base Class)
class Animal {
public:
    std::string name;

    void eat() {
        std::cout << name << " is eating..." << std::endl;
    }
};

// Child Class (Derived Class) inherits from Animal
class Cat: public Animal {
public:
    // Unique method only for Cat
    void meow() {
        std::cout << name << " Meow! " << std::endl;
    }
};

int main() {
    Cat myCat;
    myCat.name = "Momo"; // Inherited attribute from Animal

    myCat.eat();  // Inherited method from Animal
    myCat.meow(); // Cat's own method

    return 0;
}

```
